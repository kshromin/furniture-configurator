# Декоры и таблицы соответствия профилям

Палитра общая на всю линейку, но **доступность у каждого профиля своя**. Это не
формальность: заказать «Золото блестящее» на профиль Q нельзя — такого сочетания
в производстве нет.

Точки в каталоге нарисованы векторной графикой, поэтому текстом не читаются.
Таблицы ниже восстановлены из PDF скриптом `scripts/catalog.py matrix N` и сверены
с отрисованными страницами.
