# Selectel — что завести (инструкция для владельца)

Делается один раз и только вами: аккаунт и оплата — не моя часть. Всё остальное после этого делаю я.
Названия пунктов в панели могут слегка отличаться — ориентируйтесь на смысл, а не на буквы.

**Итог, ради которого всё это:** четыре вещи, которые нужно будет мне передать. Список в конце файла.

## 1. Аккаунт

1. Регистрация на `selectel.ru`, вход в панель управления.
2. **Физлицо или юрлицо — можно начать с физлица, если юрик не готов.** Selectel владельца аккаунта
   не меняет: чтобы перейти на организацию, заводится новый аккаунт и услуги переносятся на него
   (запрос в поддержку). Звучит хуже, чем есть: у нас вся площадка воспроизводится из `deploy/` и
   бэкапа за вечер, а переезд между аккаунтами — это те же шаги, что и первая установка, плюс правка
   A-записей, если сменится IP. Перейти на юрлицо стоит **до первого реального клиента с
   персональными данными**: договор с провайдером понадобится юристу как поручение на обработку, и
   он должен быть с тем лицом, которое эти данные обрабатывает. Заодно юрлицу нужны закрывающие
   документы — на физлице их не будет.
3. Пополнить баланс. Ориентир: сервер 650 ₽/мес + хранилище ~30 ₽/мес.

## 2. SSH-ключ (сделать ДО создания сервера)

Ключ — это замена пароля при входе на сервер. Создаётся на вашей машине, на сервер уезжает только
открытая половина.

В PowerShell:

```bash
ssh-keygen -t ed25519 -C "khrom-server"
```

На все вопросы можно нажать Enter (пароль на ключ — по желанию, но лучше задать). Получатся два файла
в `C:\Users\user\.ssh\`:

- `id_ed25519` — **закрытый ключ, никому не показывать и никуда не выкладывать**
- `id_ed25519.pub` — открытый, его и добавляем в панель Selectel

Содержимое открытого ключа посмотреть так:

```bash
cat ~/.ssh/id_ed25519.pub
```

В панели Selectel этот текст добавляется в раздел SSH-ключей (профиль или шаг создания сервера).

## 3. Сервер

Создать **облачный сервер, готовая конфигурация VDS 2-4-50** (2 vCPU / 4 ГБ RAM / 50 ГБ). Стек без
Coolify укладывается в ~1,8 ГБ, так что четырёх гигабайт хватает с запасом; вырастем до 4-8-80
(1 100 ₽), когда появятся чаты с гостями и боты — это перезагрузка, не переезд.

- **Регион:** Санкт-Петербург или Москва. Только не Новосибирск — он партнёрский, для 152-ФЗ хуже
  объясняется юристу
- **Образ:** Ubuntu 24.04 LTS
- **SSH-ключ:** тот, что завели на шаге 2 (не «пароль root на почту»)
- **Публичный IP:** нужен, обязательно
- **Бэкапы/снапшоты провайдера:** если предложат за отдельные деньги — не берём, у этой линейки
  локальный диск, мы делаем свои бэкапы в хранилище

После создания записать **IP-адрес сервера**.

## 4. Объектное хранилище S3

Раздел «Объектное хранилище» → создать **контейнер (бакет)**:

- **Имя:** например `khrom-files`
- **Тип:** приватный. Публичным делать не надо — что нужно раздавать наружу, откроем отдельно
- **Пул:** тот же регион, что и сервер (`ru-1`, если сервер в Питере)

Затем создать **S3-ключ** (там же, раздел ключей доступа). Появятся две строки:

- `Access Key ID`
- `Secret Access Key` — **показывается один раз**, сохраните сразу

Адрес хранилища: `https://s3.ru-1.storage.selcloud.ru` (если пул другой — адрес будет с его именем).

## 5. Что прислать мне

1. **IP-адрес сервера**
2. **Имя контейнера** S3 и **пул** (например `khrom-files`, `ru-1`)
3. **Access Key ID** и **Secret Access Key** от S3
4. Подтверждение, что вход по ключу работает — проверяется командой:

```bash
ssh root@ВАШ_IP
```

Если пустило без пароля — всё правильно.

**Про ключи и пароли.** Закрытый SSH-ключ (`id_ed25519`) не присылайте — он нужен только на вашей
машине. S3-ключи — обычные рабочие реквизиты, но в переписку их лучше не копировать: положите в файл
в папке материалов на Яндексе, я прочитаю оттуда. Пароли от аккаунта Selectel мне не нужны ни при
каком раскладе.
